## CipherBox 2.1.1

从 2.0.3 跨了一个阶段版本：**界面模式、文件关联、深色主题**都是新增的，同时修掉一个会让批量解密全部失败的严重 bug。

---

## 新功能

### 一般模式 / 专业模式
- 首次启动会问一次「选择界面模式」，之后不再打扰
- **一般模式**只显示必要选项；**专业模式**显示全部加密参数与诊断开关
- 两种模式加密出的文件**完全相同**
- 随时可以在「选项」里切换

### 深色主题
- 「选项 → 界面配色」：浅色 / 深色 / **跟随系统**
- 跟随系统读取 Windows 的「应用模式」设置
- 切换后需重启程序才生效

### 文件关联
- 「选项 → 关联 .cbx」：双击 .cbx 直接用本程序打开，右键菜单多出「解密」「查看」
- 只写当前用户的注册表（HKCU），**不需要管理员权限**

### 命令行与单实例
- 主程序接受文件路径参数（拖到 exe 图标上也能用）
- 单实例：重复启动时把文件转交给已开着的窗口
- 两个命令行工具新增 `--folder` / `--batch`：整个文件夹的加密与批量处理

---

## 重要修复

### 批量解密全部失败（严重）
密钥缓存把同一个数组交给调用方，而加密/解密的收尾会把这个数组**涂零**，
导致缓存被污染成全零密钥。

表现：批量解密时**只有第一个文件成功，后面全失败**；关掉程序重开又正常，
所以一直误以为是「批量专用 bug」。

已修复，并补了同进程往返回归测试防止复发。

### 窗口行为
- 最大化后不再能拖边缘改大小
- 最大化时拖标题栏会先还原成原尺寸再跟随鼠标（Windows 原生行为）
- 拖动还原时鼠标位置按 DPI 换算，不再跳到左上角

### 界面文字
- 深色模式下标题、状态栏、标签页文字不再发黑
- 修复浅色模式下按钮变成「蓝底黑字」的问题
- 提示气泡（ToolTip）跟随主题
